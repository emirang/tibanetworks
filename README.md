## Objetivo
Desarrollo de un sitio web responsivo, semantico y accesible para una empresa especializada en servicios de TI y cableado estructurado bajo el nombre comercial de TibaNetworks. El proposito principal es ofrecer una presencia digital profesional que funcione de manera optima tanto en computadoras de escritorio como en dispositivos moviles.

## Tecnologias utilizadas
* HTML5 para la estructuracion semantica del contenido mediante etiquetas como header, nav, main, section, article y footer.
* CSS moderno utilizando Grid y Flexbox para la maquetacion y distribucion de los elementos de la interfaz.
* Diseno responsivo implementado con media queries para adaptar la visualizacion a distintas resoluciones de pantalla.
* Git y GitHub Pages para el control de versiones y el despliegue estatico del sitio.

## Estructura de vistas
1. Inicio (index.html): Presentacion institucional de la empresa y descripcion general de la propuesta de valor.
2. Servicios (servicios.html): Detalle de las soluciones tecnologicas ofrecidas, tales como cableado estructurado, instalacion de racks y soporte tecnico.
3. Contacto (contacto.html): Formulario de comunicacion optimizado con etiquetas asociadas y campos requeridos, complementado con datos de ubicacion y horarios.

## Validacion y estandares
* Validador W3C HTML: Verificacion de la correcta sintaxis y semantica estructural en todas las paginas desarrolladas, asegurando cero errores criticos.
* Validador W3C CSS: Comprobacion de la hoja de estilos global para garantizar compatibilidad y cumplimiento de las especificaciones tecnicas.
* Accesibilidad: Uso de contraste adecuado de colores, atributos alternativos en las imagenes y asociacion correcta de etiquetas en formularios.
